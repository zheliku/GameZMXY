# Docs/ 目录规范（项目文档）

> 上级规范：`../AGENTS.md`（根规范）。冲突时：根规范 > 本文件 > 推断。

## 文档清单与维护规则

| 文件                 | 内容                                                         | 维护规则                                                                 |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------ |
| `LegacyAssetMap.md`  | 旧项目（ZMXY_BHYH）资产的 `旧路径 → 新路径` 语义映射          | 每次从旧项目搬资源/生成 `SpriteFrames .tres` 后**必须**登记（根规范 §11.3） |
| `Architecture.md`    | 本项目代码架构说明（里程碑 M7 收口时补齐）                   | 架构级决策（目录职责、红线调整）落地后同步更新                            |

## 约定

- 文档记录**事实与决策**（含日期与原因），不写未实施的设想；设想走人类裁决后进根规范。
- `LegacyAssetMap.md` 条目格式：`旧项目路径 | 新路径 | 帧规格/备注`；登记前先查重，避免同一资源多条记录。
- 框架侧的系统文档在 `Godot/docs/`，不要在 `Docs/` 里复制框架文档内容；发现框架文档与代码不符时报告（根规范 §15），不改框架文档。
- 文档与规范冲突时以 `AGENTS.md` 链为准；需要改文档结构时报告人类。
